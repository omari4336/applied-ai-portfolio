# Review Sentiment Classification

This NLP course project explores laptop-review text and trains a linear SVM with TF-IDF features for three sentiment classes.

Open [Sentiment_Classification.ipynb](Sentiment_Classification.ipynb) in a Python Jupyter kernel. Install pandas, numpy, matplotlib, seaborn, nltk, wordcloud, and scikit-learn. Place Laptop_Train_v2.csv in a local data folder next to the notebook. The prediction sections additionally use Laptops_Test_Data_PhaseA.csv and Laptops_Test_Data_PhaseB.csv. Obtain the coursework inputs separately. Run the notebook from this directory.
