# Skin Lesion Classification

This academic experiment trains and evaluates a ResNet18 classifier using PyTorch. It includes image transformations, class balancing, and classification reports.

Open [ResNet18.ipynb](ResNet18.ipynb) in a Python Jupyter kernel. Install the packages in the first cell and place HAM10000 metadata and the two image directories inside a local data folder next to the notebook. Obtain the dataset separately under its applicable terms. Run from this directory. The notebook may download pretrained weights and creates a local checkpoint during training.

This is an educational classification experiment without clinical validation.
