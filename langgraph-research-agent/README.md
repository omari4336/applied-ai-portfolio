# LangGraph Research Agent

A small research agent that routes a question between a Gemini model and Tavily search using LangGraph. The notebook includes an example query and the resulting workflow logic.

Open [Research_Agent.ipynb](Research_Agent.ipynb) in a Python Jupyter kernel. Install the packages in the first cell. Set GOOGLE_API_KEY and TAVILY_API_KEY in the kernel environment before running the notebook. Running the example calls external APIs. Provider access and model availability may affect execution.
